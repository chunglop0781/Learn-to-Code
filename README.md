# 💻 Learn-to-Code

> Những dòng code gõ vui để ôn lại bài tập của **{name}** :3

Chào mừng bạn đến với **Learn-to-Code** — một chiếc repository khá là... lung tung nhưng đầy tình yêu dành cho code. 🐧💻

Đây là nơi mình lưu lại những đoạn code được viết trong quá trình **học tập, làm bài tập, thử nghiệm và nghịch code cho vui**.

Không phải project xịn xò gì đâu, chủ yếu là:

```text
Học bài → Gõ code → Lỗi → Sửa lỗi → Chạy được → Vui → Lại học tiếp
                         ↓
                       💀
```

## 📚 Repository này có gì?

Repository chứa những bài code và bài tập được viết trong quá trình học các kiến thức lập trình, có thể bao gồm:

* 🟢 C / C++
* 🟨 JavaScript
* 🟦 Node.js
* 🌐 HTML / CSS
* 🐍 Python
* 🗄️ SQL
* 🧩 Các bài tập thuật toán
* 📝 Những đoạn code nhỏ dùng để ôn lại kiến thức
* 🧪 Code thử nghiệm linh tinh
* 🤡 Và đôi khi là những dòng code chính tác giả cũng không hiểu tại sao nó chạy

## 🎯 Mục đích

Repository này được tạo ra chủ yếu để:

* Ôn lại kiến thức đã học.
* Luyện khả năng viết code.
* Lưu lại các bài tập đã làm.
* Thử nghiệm những thứ mới.
* Nhìn lại quá trình từ **"không biết gì" → "biết thêm một tí"**. :D

Nói đơn giản hơn:

> **Code ở đây không cần hoàn hảo, chỉ cần giúp mình nhớ bài.** 💗

## 🐛 Nếu thấy code hơi... kỳ

Đừng quá bất ngờ. Đây là **code luyện tập**, không phải sản phẩm thương mại. =))

Có những đoạn có thể:

* Viết chưa tối ưu.
* Tên biến hơi... khó hiểu.
* Có cách làm tốt hơn.
* Có những đoạn nhìn lại sau vài tháng sẽ tự hỏi:

  > "Ủa hồi đó mình viết cái này thật à?" 😭

Và câu trả lời là:

> **Có. Và chúng ta sẽ không xóa nó.**

Vì đó cũng là một phần của quá trình học code. :))

## 📝 Một vài quy tắc bất thành văn

```text
1. Code được.
2. Chạy được.
3. Hiểu được.
4. Nếu không hiểu → tìm hiểu.
5. Nếu lỗi → debug.
6. Nếu vẫn lỗi → uống nước.
7. Nếu vẫn lỗi → ngủ.
8. Mai mở lại biết đâu tự nhiên hết lỗi. 🤡
```

## 🌱 Hành trình học code

Repository này giống như một cuốn sổ nháp.

Mỗi folder, mỗi file, mỗi dòng code đều là một dấu mốc nhỏ trong quá trình học.

Có thể hôm nay nhìn nó thấy bình thường, nhưng vài năm sau nhìn lại sẽ thấy:

> **"À, hóa ra mình đã từng bắt đầu từ đây."** 🥹
